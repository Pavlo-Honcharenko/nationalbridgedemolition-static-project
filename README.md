## 📝 Project Description
A fast, lightweight business site with no CMS: 8 pages (Home, Gallery, About Us, Bridge Demolition, Job Site Cleanup, On-Time Performance, Safety, Privacy) in plain HTML, CSS and JavaScript.

The homepage combines a hero with calls to action, services, an about section, client testimonials, a call-to-action band and a contact footer, plus a floating click-to-call button on every page. The gallery page shows completed projects, and every page has its own title, meta description and canonical URL.

In Lighthouse desktop (September 2026) the homepage scored **90 for performance** and **100 for SEO and best practices**.

## 🛠️ Technologies Used
- HTML5
- CSS3 (minified, split per page type)
- JavaScript with jQuery
- Responsive images (`<picture>`, lazy loading)
- On-page SEO (titles, meta descriptions, canonical URLs, sitemap.xml, robots.txt)

## ⭐ Key Features

- Click-to-call buttons and a floating call button

- Lazy-loaded images
